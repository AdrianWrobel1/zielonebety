# Objective

The Persistence Layer is the only component allowed to access the ORM.

Business modules must never know SQL, SQLAlchemy or database internals.

Persistence abstracts storage.

Nothing else.

- Bulk Operations
- Upsert
- Pagination
- Filtering
- Query Specifications
- Transaction Management

- Analytics

↓

↓

↓

SQLAlchemy

↓

# Unit of Work

Every execution owns one Unit of Work.

Responsibilities

- transaction lifecycle
- repository access
- commit
- rollback

Failures trigger rollback.

# Philosophy

The platform should answer questions like:

- What did Betclic return yesterday at 15:42?
- When did this odd change?
- Which provider changed first?
- Why did the scanner trigger?
- Can this bug be reproduced?

If the answer cannot be reproduced,

history is insufficient.
