Estimated Complexity: High

Dependencies

- Stage 07 — Scanner Engine
- Stage 08 — Notifications

---

# Objective

Build a modern, responsive web application for monitoring betting opportunities, managing providers and analyzing historical market data.

The Frontend is a presentation layer.

It never contains business logic.

All data comes exclusively from the API.

---

# Scope

Included

- Dashboard
- Authentication
- Opportunity Explorer

- Provider Status
- Historical Charts
- Scanner Dashboard
- Notification Center
- Settings
- User Preferences
- Dark Mode
- Responsive Layout

Not Included

- Scanner Logic
- Provider Logic
- Database Logic
- Direct API Integrations outside Backend

# Architecture

